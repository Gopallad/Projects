## Project Summary

Login Form is a React application built with Vite that provides a simple authentication interface. Users can switch between Login and Sign Up forms, with fields for email and password, plus a name field during registration. The forms include required-field validation, autocomplete support, and links to switch between modes.

The interface is styled with CSS and currently serves as a front-end demo: form submissions are not connected to an authentication service, and the “Forgot Password?” link has no recovery flow yet.
